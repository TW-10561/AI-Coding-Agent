## 2. コンポーネント詳細（Component Details）

### 2.1 Client Layer

| Component | Technology | Entry Point | Description |
|-----------|-----------|-------------|-------------|
| **TUI** | TypeScript + Bun | `tui/src/main.ts` | Terminal user interface with readline, 50+ commands |
| **VS Code Extension** | TypeScript + Webview | `vscode-extension/src/extension.ts` | Sidebar chat + model selector + sessions |
| **SDK** | TypeScript | `src/sdk/client.ts` | Typed HTTP client for all platform routes |

### 2.2 Platform Backend

| Component | Port | Technology | Purpose |
|-----------|------|-----------|---------|
| **Hono API Server** | 3100 | Bun + Hono 4.x | Main backend — all routes, middleware, services |
| **nginx Proxy** | 80/443 | nginx 1.24 | TLS termination, rate limiting, SSE |
| **SQLite DB** | local | bun:sqlite (WAL) | Audit, budget, task state, workspace registry |

### 2.3 AI Engine Layer

| Component | Port | Technology | Purpose |
|-----------|------|-----------|---------|
| **OpenCode** | 4096 | TypeScript/Bun | Agentic loop, session management, provider orchestration |
| **vLLM** | 8000 | Python/CUDA | Local GPU inference (Qwen3-Coder-30B) |
| **AI Gateway** | 9080 | Proxy | Routes to multiple cloud providers |

### 2.4 HITL Guard Layer

| Module | File | Purpose |
|--------|------|---------|
| RiskEngine | `HITL/riskEngine.ts` | Scores action risk (0–1 scale) |
| DestructiveGuard | `HITL/destructiveGuard.ts` | Blocks destructive shell commands |
| NetworkGuard | `HITL/networkGuard.ts` | Restricts external network calls |
| SensitiveFiles | `HITL/sensitiveFiles.ts` | Protects `.env`, keys, certs |
| LoopGuard | `HITL/loopGuard.ts` | Detects infinite agentic loops |
| SandboxRunner | `HITL/sandboxRunner.ts` | Executes commands in isolation |
| AuditLogger | `HITL/auditLogger.ts` | Records all HITL decisions |
| Autonomy | `HITL/autonomy.ts` | Per-agent autonomy mode control |
| RBAC | `HITL/rbac.ts` | Role-based access control |
| SkillTrust | `HITL/skillTrust.ts` | Skill-level trust evaluation |
