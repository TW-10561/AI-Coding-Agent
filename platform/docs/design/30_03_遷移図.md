## 3. リクエストフロー（Request Flow）

### 3.1 Chat Request Flow (Platform → OpenCode → LLM)

```
  [TUI / VS Code Extension]
         │
         │  POST /api/sessions/:id/prompt
         ▼
  ┌─────────────────────────────────────┐
  │  Platform API (:3100)               │
  │                                     │
  │  1. Auth middleware                 │
  │  2. Rate limit check                │
  │  3. Budget pre-flight check         │
  │  4. HITL risk assessment            │
  │  5. Skill RAG injection             │
  │  6. Audit log: request start        │
  └──────────────┬──────────────────────┘
                 │  POST /api/session/:id/message
                 ▼
  ┌─────────────────────────────────────┐
  │  OpenCode Engine (:4096)            │
  │                                     │
  │  AGENTIC LOOP (max 15 rounds):      │
  │  ┌─────────────────────────────┐    │
  │  │  1. Build prompt + context  │    │
  │  │  2. Call LLM with tools     │    │
  │  │  3. Parse tool calls        │    │
  │  │  4. Execute tools           │    │
  │  │  5. Feed results back       │    │
  │  │  6. Check termination       │    │
  │  └─────────────────────────────┘    │
  └──────────────┬──────────────────────┘
                 │  HTTP/SSE
                 ▼
  ┌─────────────────────────────────────┐
  │  LLM Inference                      │
  │  vLLM (:8000) or Gateway (:9080)    │
  │                                     │
  │  Model: Qwen3-Coder-30B-A3B         │
  │  Mode: XML text-based tool calling  │
  └─────────────────────────────────────┘
                 │
                 │ response streams back
                 ▼
  Platform → Client (SSE or JSON)
```

## 4. エラー遷移（Error Transitions）

| Error | Screen | Recovery Path |
|-------|--------|---------------|
| Platform offline | TUI-015: Red panel | Retry `/status`, check :3100 |
| OpenCode offline | TUI-015: Red panel | Check :4096, restart |
| Budget exceeded | TUI-015: Budget error | `/budget set` to increase limit |
| Rate limit hit | Auto retry or TUI-015 | Wait 60s |
| HITL denied | TUI-015: HITL blocked | Human approves or reformulate |
| LLM timeout | TUI-015: Timeout error | Retry or simplify prompt |
| Skill not found | TUI-015: Skill error | `/skills` to list available |

## 5. キーボードショートカット（Keyboard Shortcuts）

| Key | Action | Screen |
|-----|--------|--------|
| Enter | Send message | MAIN PROMPT |
| `\` + Enter | Continue to next line (multiline) | MAIN PROMPT |
| `"""` Enter | Toggle multiline block mode | MAIN PROMPT |
| Tab | Command autocomplete (50+ commands) | MAIN PROMPT |
| Ctrl+C | Graceful shutdown | Any |
| Ctrl+D | Exit (EOF) | Any |
| Up/Down Arrow | Command history | MAIN PROMPT |
