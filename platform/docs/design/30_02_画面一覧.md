# 30_02 画面一覧（Screen List）

**Project:** Thirdwave AI Coding Platform  
**Version:** 1.0  
**Date:** 2026-03-26  
**Status:** Final Design

---

## 概要（Overview）

Thirdwave platform has three distinct client interfaces:
1. **TUI (Terminal User Interface)** — Primary developer CLI
2. **VS Code Extension** — Editor-integrated AI assistant
3. **Web Dashboard** — Browser-based status page at `http://localhost:3100/`

---

## 5. 画面共通規則（Common Screen Rules）

| Rule | TUI | VS Code |
|------|-----|---------|
| Max width | 100 chars | Panel width (responsive) |
| Color theme | Purple primary, cyan accent | VS Code theme variables |
| Error display | Red panel with `✗` | Red toast notification |
| Success display | Green `✓` marker | Green checkmark |
| Loading | Braille spinner | Pulsing dots |
| Code blocks | Syntax highlighted (chalk) | VS Code syntax highlight |
| Markdown | marked + marked-terminal | Custom HTML renderer |
