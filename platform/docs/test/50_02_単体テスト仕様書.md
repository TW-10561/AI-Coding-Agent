## 1. 概要（Overview）

本書は、Thirdwave AI Coding Platform の単体テスト（Level 1）およびコンポーネントテスト（Level 2）のテストケース仕様を定義する。各テストケースは対象関数/クラス、入力、期待出力、合格基準を明示する。

### 1.1 テストフレームワーク

```typescript
// Bun test runner
import { describe, test, expect, mock, beforeEach, afterEach } from "bun:test"
```

### 1.2 テスト実行コマンド

```bash
# 全単体テスト
bun test --filter "unit"

# 特定サービス
bun test platform/tests/unit/policy-engine.test.ts

# カバレッジ付き
bun test --coverage
```

```typescript
// Example test
describe("RiskEngine", () => {
  const engine = new RiskEngine()

  test("PE-U-001: safe command scores 0", () => {
    const result = engine.assess({ command: "ls -la" })
    expect(result.score).toBe(0)
    expect(result.level).toBe("low")
    expect(result.recommendation).toBe("allow")
  })

  test("PE-U-002: rm -rf scores critical", () => {
    const result = engine.assess({ command: "rm -rf /" })
    expect(result.score).toBeGreaterThanOrEqual(85)
    expect(result.recommendation).toBe("deny")
  })
})
```
