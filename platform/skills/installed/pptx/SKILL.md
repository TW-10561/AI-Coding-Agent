## Presentation Best Practices

1. **Follow the 6x6 rule** (max 6 bullets, 6 words per bullet)
2. **Use high-quality images**
3. **Maintain visual consistency** with master slides
4. **Minimize text** per slide
5. **Use readable fonts** (sans-serif)
6. **Ensure color contrast** for accessibility
7. **Include speaker notes** for reference
8. **Test multimedia** before presenting
9. **Maintain consistent branding**
10. **Proofread carefully** for errors

## Dynamic Generation Tips

1. **Use templates** for consistency
2. **Automate data integration** from databases
3. **Generate charts dynamically** from live data
4. **Batch create presentations** for distribution
5. **Include table of contents** for long presentations
6. **Use consistent numbering** and references
7. **Include presenter notes** automatically
8. **Validate generated content** before export
