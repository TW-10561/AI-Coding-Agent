# Find Skills

Discover and install agent skills to extend your AI agent's capabilities with specialized domain knowledge.

## Use Cases
- Discovering available skills in your environment
- Finding skills for specific domains (testing, deployment, etc.)
- Installing skills from verified sources
- Managing skill dependencies and compatibility

## Example Usage

```
Ask the agent: "Find me a skill for API design"
The agent will search available skills and provide installation options.
```

## Available Domains
- Frontend & Web Design
- Backend & Architecture
- Testing & Quality Assurance
- Cloud & DevOps
- Documentation & Workflows
- React & Modern Frameworks

## Best Practices
1. Review skill documentation before installation
2. Check compatibility with your project type
3. Test skills in development environment first
4. Keep skills updated regularly
