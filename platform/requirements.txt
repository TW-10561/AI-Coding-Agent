# ─────────────────────────────────────────────────────────────────────
# Artemis AI Coding Platform — Requirements
# ─────────────────────────────────────────────────────────────────────
#
# This file lists everything needed to run Artemis.
# For developers joining the team — install these, then follow DEPLOY.md.
#

# ═══════════════════════════════════════════════════════════════════════
# SERVER-SIDE REQUIREMENTS (on the machine running Artemis)
# ═══════════════════════════════════════════════════════════════════════

## Runtime
# Bun >= 1.3.0           — JavaScript/TypeScript runtime (replaces Node.js)
#   Install: curl -fsSL https://bun.sh/install | bash
#   Verify:  ~/.bun/bin/bun --version

## OpenCode Engine
# opencode >= 1.2.17     — AI coding engine (manages sessions, file context)
#   Install: curl -fsSL https://opencode.ai/install | bash
#   Verify:  ~/.opencode/bin/opencode --version
#   Docs:    https://opencode.ai/docs

## System packages (Ubuntu/Debian)
# nginx >= 1.18          — Reverse proxy (optional, for port 80 access)
#   Install: sudo apt install nginx
# systemd                — Service manager (already on most Linux distros)

## GPU / AI Model Server (at least ONE required)
# vLLM >= 0.5.0          — GPU inference server
#   Install: pip install vllm
#   Run:     vllm serve MODEL_NAME --port 8000
#   Docs:    https://docs.vllm.ai/
#
# Ollama >= 0.5.0        — Alternative inference server (easier setup)
#   Install: curl -fsSL https://ollama.com/install.sh | sh
#   Run:     ollama serve
#   Docs:    https://ollama.com/

# ═══════════════════════════════════════════════════════════════════════
# CLIENT-SIDE REQUIREMENTS (on developer machines using the CLI)
# ═══════════════════════════════════════════════════════════════════════

## Required
# bash >= 4.0            — Shell (macOS/Linux default)
# curl >= 7.68           — HTTP client
# python3 >= 3.8         — Code block parsing (already on most systems)

## Optional
# jq >= 1.6              — JSON processing (not required, python3 is used)

## Root Monorepo Dev Dependencies
# turbo@2.5.6            — Monorepo build system
# @tsconfig/bun@1.0.9    — Shared TS config for Bun

# ═══════════════════════════════════════════════════════════════════════
# NETWORK REQUIREMENTS
# ═══════════════════════════════════════════════════════════════════════

## Ports used:
# 3100                   — Artemis platform API (internal)
# 80                     — Nginx reverse proxy (external, optional)
# 4096                   — OpenCode engine (internal)
# 8000                   — vLLM primary (GPU server)
# 31254                  — Ollama gateway (optional second GPU server)

## Firewall rules needed:
# Allow inbound TCP 80   — For users to access the API
# Allow outbound to vLLM — Platform → GPU server(s)
# Allow outbound HTTPS   — For cloud provider API calls (if configured)
