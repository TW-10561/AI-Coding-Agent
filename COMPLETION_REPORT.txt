🔐 SECURITY POLICIES IMPLEMENTED
═══════════════════════════════════════════════════════════════════════════════

✅ 1. EXECUTION SANDBOX
   Location: src/sandbox/sandboxRunner.ts
   Features:
     • HostRunner - Direct host execution
     • DockerRunner - Isolated container execution
     • Memory/CPU limits (512m/1 core default)
     • Network isolation (--network=none)
     • Read-only filesystem mounts
   Integration: bash.ts tool

✅ 2. SENSITIVE FILE PROTECTION  
   Location: src/security/sensitiveFiles.ts
   Features:
     • 54 regex patterns for sensitive files
     • Detects: .env, SSH keys, API keys, credentials
     • Risk scoring (+70 points)
     • Audit logging
   Integration: Risk engine, permission checks

✅ 3. RISK-BASED PERMISSION SYSTEM
   Location: src/permission/riskEngine.ts
   Features:
     • Dynamic risk scoring (0-100 scale)
     • Risk levels: Critical (≥80), High (≥60), Medium (≥40), Low (<40)
     • Configurable thresholds
     • Autonomy mode multipliers
     • Comprehensive factor analysis
   Integration: bash.ts tool

✅ 4. DESTRUCTIVE ACTION GUARDRAIL
   Location: src/security/destructiveGuard.ts
   Features:
     • Pre-check pattern matching
     • Severity levels: Critical (95), High (85), Medium (60), Low (30)
     • Patterns: rm -rf, chmod 777, git --force, DROP DATABASE, etc.
     • Always requires approval if matched
   Integration: bash.ts (executed first)

✅ 5. LOOP DETECTION (DOOM LOOP v2)
   Location: src/agent/loopGuard.ts
   Features:
     • Command repetition detection
     • Error repetition detection
     • Low uniqueness detection
     • High error rate detection
     • 60-second sliding window (configurable)
     • Command frequency tracking
   Integration: bash.ts tool

✅ 6. NETWORK ACCESS POLICY
   Location: src/security/networkGuard.ts
   Features:
     • Three modes: Allow, Deny, Allowlist
     • Domain pattern matching with wildcards
     • IPv4 and IPv6 support
     • Internal network bypass
     • Docker network isolation
   Integration: webfetch, websearch, external APIs

✅ 7. SKILL-LEVEL TRUST SYSTEM
   Location: src/security/skillTrust.ts
   Features:
     • Three trust levels: Trusted, Restricted, Untrusted
     • Behaviors: allow, ask, sandbox
     • Metadata tracking (author, version, verified)
     • Risk factor documentation
   Integration: skill tool, all components

✅ 8. ROLE-BASED ACCESS CONTROL (RBAC)
   Location: src/security/rbac.ts
   Features:
     • Four roles: Admin, Developer, ReadOnly, Autonomous Agent
     • Fine-grained permissions per role
     • Custom policy overrides
     • Permission hierarchy checking
     • Decision explanation generation
   Integration: All tools

✅ 9. AUDIT LOGGING (Enterprise)
   Location: src/audit/auditLogger.ts
   Features:
     • Tamper-evident logging (hash-chained)
     • JSONL format (.opencode/audit/audit.log.jsonl)
     • Event filtering and querying
     • Integrity verification
     • Append-only security
   Integration: All policies, all tools

✅ 10. AGENT AUTONOMY MODES
   Location: src/agent/autonomy.ts
   Features:
     • Supervised (1.5x multiplier, 5 iterations)
     • Semi-Autonomous (1.0x multiplier, 10 iterations)
     • Fully Autonomous (0.7x multiplier, 20 iterations)
     • Mode-based risk threshold adjustment
     • Max iteration enforcement
   Integration: bash.ts, agent loop

⚙️ CONFIGURATION SUPPORT
═══════════════════════════════════════════════════════════════════════════════

All policies are configurable via opencode.json:

{
  "security": {
    "execution_mode": "host|sandbox",
    "risk_policy": "static|dynamic|hybrid",
    "risk_thresholds": {
      "deny": 80,
      "ask": 40
    },
    "network": {
      "mode": "allow|deny|allowlist",
      "allow_domains": [...]
    },
    "sandbox": {
      "memory_limit": "512m",
      "cpu_limit": "1",
      "image_tag": "node:20-alpine"
    },
    "skill_trust": {
      "skill_name": "trusted|restricted|untrusted"
    },
    "loop_detection": {
      "enabled": true,
      "threshold": 50,
      "window_ms": 60000
    },
    "audit_logging": {
      "enabled": true,
      "directory": ".opencode/audit"
    },
    "user_role": "admin|developer|readonly|autonomous_agent"
  },
  "agent_autonomy": {
    "mode": "supervised|semi_autonomous|fully_autonomous",
    "max_iterations": 10
  }
}

🎯 EXECUTION FLOW IN BASH TOOL
═══════════════════════════════════════════════════════════════════════════════

Command Input
    ↓
Load Configuration
    ↓
Initialize Security Systems (RiskEngine, SandboxFactory, AuditLogger, LoopGuard)
    ↓
GATE 1: Destructive Command Guard (pre-check)
    ├─ If matched → require approval → audit log
    └─ Always first, always checked
    ↓
GATE 2: Sensitive File Detection
    ├─ Check if touching sensitive file
    ├─ If detected → increase risk score → audit log
    └─ 54 patterns for .env, keys, credentials
    ↓
GATE 3: Dynamic Risk Assessment (if enabled)
    ├─ Compute risk score (0-100)
    ├─ Apply autonomy multipliers
    ├─ Compare to thresholds
    └─ If score >= ask threshold → require approval
    ↓
GATE 4: Loop Detection (if enabled)
    ├─ Track command/error history
    ├─ Compute loop score
    └─ If score >= threshold → require approval
    ↓
Execute Command
    ├─ Select execution mode (host/sandbox based on config)
    ├─ Stream output with metadata
    └─ Track execution
    ↓
Audit & Report
    ├─ Log all decisions
    ├─ Record execution details
    ├─ Include security metadata
    └─ Return results
    ↓
Output with Metadata

📊 SECURITY SCORES & THRESHOLDS
═══════════════════════════════════════════════════════════════════════════════

RISK LEVELS:
  Critical (80-100):  Auto-deny or requires approval
  High (60-79):       Requires approval
  Medium (40-59):     Monitoring, may require approval
  Low (0-39):         Allowed with audit trail

THRESHOLDS (configurable):
  Deny:  >= 80 (default)
  Ask:   >= 40 (default)

RISK FACTORS:
  Destructive commands:    30-95 points (based on severity)
  Package installation:    40 points
  Network/external calls:  30 points
  Sensitive files:         70 points
  Large diffs:            30-50 points
  Delete operations:       40 points
  Loop indicators:        20-50 points
  High iterations:        20 points
